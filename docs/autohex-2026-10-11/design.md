# AutoHex implementation contract (2026-10-11)

Independent new game, not a replacement for `card_hex.html`. Six local factions on a radius-18 hexagon (1,027 cells), one human + five AI or six-AI spectator. No network players. Shared FuGames visual language. Parent/root owns index, shared icons, commits and push; workers own separate files.

## Campaign rules

- Six homes at the centers of the six edges, each with a permanent visible home anchor and a small initial foothold. Each faction has its own directed opposite-edge goal; antipodal factions share an axis but travel in opposite directions. Anchors cannot be stolen or destroyed. Losing the front therefore still permits home rebuilding.
- Normal placement and every spatial card use the same public deployment radius: a target must be within hex distance 5 of an existing valid **own** stone before the action. Enemy pieces, allies and hidden markers never extend range. Pair/triple actions validate all targets before spending anything. A bridge joins existing own endpoints (distance zero to own stones), not a remote placement exception.
- Seeded sixfold-symmetric river/hill terrain. River cells need public engineering before occupation; hills add one capture-defense strength (not a consumable shield). No terrain randomness creates permanent inaccessible starting positions. Bridges join existing own stones 2–5 hexes apart in any direction; their exact geometric segments may not cross, reverse, duplicate, overlap or create a T junction. Common endpoints are legal. This larger-board bridge range is separate from original Hex.
- Connected supply starts at the home anchor and follows own neighboring stones/bridges. Unsupplied fronts can act while reconnecting but retreat after six owner turns; anchors are permanent. Bound each faction's footprint (about 96 stones) and offer legal withdrawal/rebuilding to keep the board active.
- One action per turn, energy regenerates equally at the start of each own turn (cap 8; proposed +3), no card chains. Everyone draws from one shared shuffled pool, hand cap 5, discards reshuffled only when the draw pile is empty. Same initial hand size and replenishment rules. No draw advantage tied to ranking, AI name or human identity. At least turret, destruction, bridge, reroute, shield and exchange cards; finite physical card conservation despite recycling.
- Default AI step interval 0.30 seconds. A campaign lasts **600,000 ms of foreground unpaused active time**, not simulated turn time. At complete-round boundaries, check all six supplied routes together: first arrival at the opposite edge gives 12 points, continuous holding 2 per following round, and reconnection after a 12-round cooldown gives 6. Arrival alone does not end the campaign. Capturing or destroying a stone gives 1 point. At timeout rank all existing scores together; a partial final round adds no extra route credit. Tied top scores are a draw/shared top rank, never alliance-wide automatic victory. After results offer optional sandbox continuation. Pauses/background/ready state do not count. A safety iteration cap in tests is not a fake ten-minute timer.
- Battles must continue meaningfully through the window: repeatable deck, contested opposite edges, supply attrition and limited footprints. Validate actual actions/captures/engineering/card uses in late campaign, not just time elapsed. Report evidence rather than guaranteeing all seeds remain balanced.

## Diplomacy

Public offers, acceptance/rejection, limited-duration nonaggression pacts (proposed 12 rounds), max two allies each. Offers expire, have a per-player cooldown, and each decision consumes an ordinary turn. Allies do not share hands or victory; attacks against an ally require explicit betrayal first. Betrayal costs an action, energy and a visible score/reputation penalty, with longer diplomacy cooldown/grudge. Turrets do not silently damage active allies. AI evaluates public common threats, nearby borders and standings; profiles differ but no identity-based win bonuses. Humans have the same offer/accept/reject/betray actions.

## Frozen integration API (agree changes with root and other workers)

`autohex-engine.js`: CommonJS export and browser `window.AutoHex`, no DOM dependencies.

Exports: `Game`, `RADIUS`, `COUNT`, `CELLS` (q,r,s,i,x,y world positions), `ADJ`, `index(q,r)`, `distance(a,b)`, `PLAYERS` (1..6), `CARD_META` (type -> label,cost,slots,description), `legalAction(observation,action)`, `chooseAction(observation)`, bridge conflict helpers, and any public supply/range helpers tests need.

`new Game({seed, first=1, rotation=0, durationMs=600000})`; methods `start()`, `pause()`, `reset(seed?, first?, rotation?)`, `act(action)` boolean/atomic, `observation(player=this.turn)`, `advanceTime(deltaMs)` (only while running), `continueSandbox()`.

State/public view: `phase` ready/running/paused/over, `turn`, `ply`, `round`, `activeMs`, `durationMs`, `sandbox`, `result`; `board` owner array, `terrain`, `roads`, `anchors` owner array, `bridges` {owner,a,b}, `turrets` {owner,cell,... countdown}, `shields`; `players` indexed 1..6 with `home,axis,sign,score,energy,profile,name`; `offers`, `alliances`, bounded `events`; observer's `hand`, public `handCounts`, `drawCount`, `discardCount`. Never expose draw order or other hands. Agent may add public fields and document them. Raw Game holds shared `drawPile`, `discardPile`, `hands` for conservation tests only.

Actions `{type,cells:[],target?,cardIndex?}`. Spatial base actions `deploy`, `engineer`, `withdraw`; `rest` and `discard` are single-turn recovery/card management actions. Cards include `turret`, `destroy`, `bridge`, `reroute`, `shield`, `exchange`. Diplomacy `offer`, `accept`, `reject`, `betray` with target player. Prefer metadata for UI arity; explain source vs destination semantics clearly. New game can omit hidden traps; no unrevealed data participates in deployment radius.

`autohex.html`, `autohex-ui.js`, `autohex.css`: standalone page with theme/icon links; canvas large map, wheel/pinch zoom, pointer drag, touch selection, minimap with camera rectangle and click-to-pan, six-faction status, directed goals/home labels, clear card cost/energy/range/terrain legend, compact public diplomacy/log. Expose `window.autoHexGame`, `window.autoHexRender`, `window.autoHexSchedule` for real browser QA. UI uses public observation for rendering private information and always calls shared legality. One cancellable scheduler with generation tokens; active clock separate from step pacing, reset on pause/restart/visibility.
