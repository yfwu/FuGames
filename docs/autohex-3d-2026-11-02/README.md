# AutoHex-3D：3D 即時指揮版（2026-11-02）

`autohex_3d.html` 是 AutoHex 的 3D 版本：Civilization 式的立體六角地形與據點，加上 RTS 式的即時指揮節奏。設計主軸是**補給線**、**陣地**與**抽卡**。

## 規則一致的做法

3D 頁不另寫任何規則。它與 `autohex.html` 載入同一組腳本（`hex-strategies.js` → `autohex-planner.js` → `hex-core.js` → `autohex-engine.js` → `autohex-visuals.js`），並使用同一個 `autohex-ai-worker.js`。合法性（`legalAction` / `legalSelection`）、花費、補給配送、斷補撤退、計分、外交、中立事件、十分鐘計時與 AI 決策全部由同一個 `HexCore` 實例處理。

新增的三個檔案只做呈現與下令：

| 檔案 | 內容 |
| --- | --- |
| `autohex3d-logic.js` | 唯讀分析：補給弱點（Tarjan 割點）、補給／陣地報表、牌池配方、指令佇列的解析與合法性重檢、3D 點選座標換算 |
| `autohex3d-render.js` | 零依賴 WebGL2：實例化基本形（偏航、俯仰、翻滾）、柔邊粒子、環繞鏡頭與震動、射線點選、螢幕投影 |
| `autohex3d-scene.js` | 戰場造型：地塊配色、城堡、炮台、道路、橋、地道、機場、物資站、卡車、飛機，以及煙／火／塵粒子模擬 |
| `autohex3d-ui.js` | 遊戲迴圈、HUD、指令列、手牌、佇列、側欄、事件特效；只呼叫 `game.act / start / pause / advanceTime / continueSandbox / observation` |

`tests/autohex-3d.test.cjs` 固定這個邊界：腳本順序與 AutoHex 相同、3D 程式碼不直接寫入任何棋盤欄位或私有方法、只呼叫上列公開方法。瀏覽器試玩把頁面上的完整行動序列（人類、AI、佇列、逾時）送回 Node 引擎重放，要求棋盤、存糧與分數完全一致。

## 三路前線擴充（可關閉的規則模組）

把三路前線的後方建設帶進 AutoHex-3D。規則寫在共用的 `hex-core.js`，以 `new Game({ expansion: true })` 開啟；AutoHex 與 MiniHex 不開啟，關閉時與原本完全相同（測試比對同 seed 的行動序列與棋盤）。AutoHex-3D 預設開啟，設定中的「三路前線擴充」可關閉。

| 建築 | 花費 | 條件 | 效果 |
| --- | --- | --- | --- |
| 兵工廠 | 4 能量＋8 物資 | 連通家園、3 格內沒有敵子的己方棋子 | 每 6 次己方回合，若仍連通且物資 ≥ 3，花 3 物資放出無人機，鎖定 9 格內最近的敵方非家園棋子（同時最多 2 架） |
| 防空砲 | 3 能量＋當地 1 存糧 | 任一己方棋子（可在前線） | 敵方無人機飛進 3 格、或敵方空投／轟炸目標在 3 格內：花 1 存糧擊落；空中行動照付能量、物資與冷卻 |
| 補給工坊 | 3 能量＋5 物資 | 同兵工廠的後方條件 | 連通時每次己方行動物資庫 +2 |

- 一格一座建築，各方兵工廠 1 座、防空砲與工坊各 2 座；棋子失守建築消失；建築格不能再架炮台或換位，地道內部也不能蓋。
- 無人機在己方回合開始時移動，每次 3 格，抵達目標旁攻擊（等同炮擊，護盾可擋、得 1 分）；目標消失會改鎖附近目標；5 次己方回合沒命中就耗盡。
- 切斷兵工廠或工坊的補給，它們就停工——補給線仍是核心。
- AI：長程收益無法在三步推演中看見，因此建造由一組公開、可重現的規則決定（優先在受空中或無人機威脅處架防空砲，其次在後方開工坊與兵工廠），其餘行動仍交給原本的規劃器。Worker 與頁面內運算結果相同。
- 畫面：磚造兵工廠（鋸齒屋頂、冒煙煙囪、出機倒數）、雙管防空砲（追瞄無人機或敵方機場）、補給工坊（倉庫、吊車、木箱）、四旋翼無人機（旋翼轉動、平滑飛行、俯衝攻擊）、防空曳光與空中爆炸；被攔截的轟炸機會中彈冒煙、不投彈。
- 平衡為初步：兩個固定 seed、各 1,800 手的 AI 對局中，開啟擴充後總擊毀數約為原版的 1.4–2.1 倍（無人機命中 113–160 次、被擊落 114–141 次），接通對岸次數相近（6→11、10→10），最高分因無人機擊毀計分而偏高。第一版（每方 2 座兵工廠、每 5 回合出機）在完整十分鐘戰役中無人機擊毀 406 次、壓過其他戰法，因此改為每方 1 座、每 6 回合。尚無真人遊玩數據。

## 戰場造型（2026-11-02 第二版）

依兩輪回饋調整，全部仍由公開棋盤狀態推導：

- **占領＝地塊變色**：被占的六角格本身變成陣營色（斷補時偏灰），不再在上面疊一層底座、沙包、帳篷或旗子。狀態都放在地塊自己的邊緣：斷補是紅色脈動邊、工事是深色邊、護盾是紫色邊。易手時地塊顏色淡入；被砲擊、轟炸或空投的格子，等彈藥或物資落地才變色。
- **補給線運輸**：補給樹畫成柏油路（路肩、分隔線、路口）。帆布篷軍用卡車（駕駛室、擋風玻璃、六輪）靠一側車道行駛，起步減速、轉彎沿路面朝向；從家園裝貨、到上一次實際收到補給的陣地卸貨（停留）、空車返回；過橋走橋面、進地道時消失；有車燈、排氣與地面陰影。
- **炮擊**：砲塔砲管對準下一個目標；開火時砲管後座、砲口閃光與砲口煙；砲彈依拋物線飛行，拖曳煙跡、有曳光與地面陰影。
- **爆炸**：短暫閃光、火球（上升並轉暗）、翻滾的濃煙柱隨風飄散、土塊依重力落地、火花、沿地面擴散的塵環；彈坑焦痕約 30 秒，彈坑持續冒煙燃燒一段時間；鏡頭附近的爆炸會讓畫面輕微震動。
- **航空轟炸**：雙發轟炸機從跑道滑行、抬頭起飛，沿曲線爬升並傾斜轉彎進入航線，開彈艙投下一串四枚炸彈（依飛行速度與高度計算落點，第三枚命中目標），炸彈沿彈道下墜、機頭朝下；之後爬升離場。引擎拖煙、地面有機影。被護盾擋下的那一枚改為藍色閃光。
- **空投**：運輸機同樣起飛進場，投下的木箱先自由落下再開傘、擺盪落地，揚起塵土後才出現新炮台。
- **煙、火、塵**：改用柔邊的面向鏡頭粒子（煙與塵為一般混色、閃光與火花為加光），並套用與地形相同的距離霧。
- 暫停時所有戰場動畫凍結，鏡頭仍可操作；系統「減少動態」偏好時不播放卡車、飛機與粒子動畫。

## 補給線

- 馬路與卡車：每方從家園沿相鄰格、橋梁、地道向外的補給樹（`AutoHexVisuals.supplyForest`）畫成道路，卡車開往上次收到補給的陣地。
- 斷補：地塊邊緣紅色脈動，頭上數字是剩餘存糧。
- 斷補：紅色脈動外框，頭上數字是剩餘存糧（耗盡即撤退）；側欄「斷補中」依存糧排序，點按跳到該格。
- **補給弱點**（橘色、`−N`）：一失守就讓 N 枚己方棋子斷補的格子。**斷補目標**（紅色、`✂N`）：敵方最脆弱的節點。兩者與 AutoHex 的「斷補預覽」是同一個計算；測試逐格比對 `supplyCutPreview`。
- 側欄量表：後方物資庫、每次產出（家園 4 + 物資站 ×2）、運距預算、連通棋子、距對岸、機場／物資站。

## 陣地

- 山丘以山形呈現；工事（持守 31 次）為城垛外框；護盾為半透明罩；炮台為塔，頭上顯示射擊倒數，缺糧時灰色。
- 「陣地」圖層把所有炮台的 3 格射程鋪在地面上；側欄列出炮台倒數、壽命、是否缺糧，以及山丘撤退倒數。
- 機場（跑道＋塔，啟用時亮起）與物資站（箱子）位置隨 seed。

## 抽卡

手牌以卡片呈現（費用、格數、效果、期限），新抽到的卡會翻入。牌堆區顯示牌堆／棄牌／重洗次數與公開配方比例條（每席 13 張：改接 4、炮台／拆除／橋梁／換位各 2、護盾 1）。牌序與他人手牌不公開。破陣令是公開儲備，取得後出現在指令列。數字鍵 1–5 選牌。

## 即時指揮（介面層，不改規則）

- **指揮時限**：輪到你時的秒數（30／20／12 秒，預設 20；「不限」同 AutoHex）。只計算未暫停的前景時間；逾時自動執行「休整」，這本來就是合法行動。
- **指令佇列**：AI 行動時，選指令或手牌再點格子即可預約（最多 4 個）。預約時以「假設輪到你」的視圖（回合開始的 +3 能量）檢查；輪到你時以核心重新檢查，第一個仍合法的指令自動執行，失效的移除並提示。卡牌指令記卡種不記位置。
- 戰局連續進行：AI 依設定步速出手、十分鐘前景計時、鏡頭與特效（炮擊拋物線、空投飛機、攻占波紋、斷補撤退煙霧、中立事件雷擊）即時播放。

## 操作

滑鼠左鍵拖曳平移、右鍵（或 Shift／Alt＋拖曳）旋轉俯仰、滾輪縮放；觸控單指平移、雙指縮放與旋轉；WASD／方向鍵平移、Q／E 旋轉、＋／－縮放、H 家園、F 前線、R 休整、空白鍵／P 暫停、Esc 取消。右上按鈕：家園、前線、全圖、旋轉 60°；右下小地圖點按跳轉。無 WebGL2 時顯示說明並連到平面版。
