# AutoHex-3D：3D 即時指揮版（2026-11-02）

`autohex_3d.html` 是 AutoHex 的 3D 版本：Civilization 式的立體六角地形與據點，加上 RTS 式的即時指揮節奏。設計主軸是**補給線**、**陣地**與**抽卡**。

## 規則一致的做法

3D 頁不另寫任何規則。它與 `autohex.html` 載入同一組腳本（`hex-strategies.js` → `autohex-planner.js` → `hex-core.js` → `autohex-engine.js` → `autohex-visuals.js`），並使用同一個 `autohex-ai-worker.js`。合法性（`legalAction` / `legalSelection`）、花費、補給配送、斷補撤退、計分、外交、中立事件、十分鐘計時與 AI 決策全部由同一個 `HexCore` 實例處理。

新增的三個檔案只做呈現與下令：

| 檔案 | 內容 |
| --- | --- |
| `autohex3d-logic.js` | 唯讀分析：補給弱點（Tarjan 割點）、補給／陣地報表、牌池配方、指令佇列的解析與合法性重檢、3D 點選座標換算 |
| `autohex3d-render.js` | 零依賴 WebGL2：實例化六角柱、圓柱、錐、球等基本形，環繞鏡頭、射線點選、螢幕投影 |
| `autohex3d-ui.js` | 遊戲迴圈、HUD、指令列、手牌、佇列、側欄、事件特效；只呼叫 `game.act / start / pause / advanceTime / continueSandbox / observation` |

`tests/autohex-3d.test.cjs` 固定這個邊界：腳本順序與 AutoHex 相同、3D 程式碼不直接寫入任何棋盤欄位或私有方法、只呼叫上列公開方法。瀏覽器試玩把頁面上的完整行動序列（人類、AI、佇列、逾時）送回 Node 引擎重放，要求棋盤、存糧與分數完全一致。

## 補給線

- 細線＋流動光點：每方從家園沿相鄰格、橋梁、地道向外的補給樹（`AutoHexVisuals.supplyForest`），光點由家園往前線流動；己方較亮。
- 斷補：紅色脈動外框，頭上數字是剩餘存糧（耗盡即撤退）；側欄「斷補中」依存糧排序，點按跳到該格。
- 棋子邊緣的小方塊是存糧（未滿或斷補時顯示）；青點表示上次送達。
- **補給弱點**（橘色、`−N`）：一失守就讓 N 枚己方棋子斷補的格子。**斷補目標**（紅色、`✂N`）：敵方最脆弱的節點。兩者與 AutoHex 的「斷補預覽」是同一個計算；測試逐格比對 `supplyCutPreview`。
- 側欄量表：後方物資庫、每次產出（家園 4 + 物資站 ×2）、運距預算、連通棋子、距對岸、機場／物資站。

## 陣地

- 山丘以山形呈現；工事（持守 31 次）為城垛外框；護盾為半透明罩；炮台為塔，頭上顯示射擊倒數，缺糧時灰色。
- 「陣地」圖層把所有炮台的 3 格射程鋪在地面上；側欄列出炮台倒數、壽命、是否缺糧，以及山丘撤退倒數。
- 機場（跑道＋塔，啟用時亮起）與物資站（箱子）位置隨 seed。

## 抽卡

手牌以卡片呈現（費用、格數、效果、期限），新抽到的卡會翻入。牌堆區顯示牌堆／棄牌／重洗次數與公開配方比例條（每席 13 張：改接 4、炮台／拆除／橋梁／換位各 2、護盾 1）。牌序與他人手牌不公開。破陣令是公開儲備，取得後出現在指令列。數字鍵 1–5 選牌。

## 即時指揮（介面層，不改規則）

- **指揮時限**：輪到你時的秒數（30／20／12 秒，預設 20；「不限」同 AutoHex）。只計算未暫停的前景時間；逾時自動執行「休整」，這本來就是合法行動。
- **指令佇列**：AI 行動時，選指令或手牌再點格子即可預約（最多 4 個）。預約時以「假設輪到你」的視圖（回合開始的 +3 能量）檢查；輪到你時以核心重新檢查，第一個仍合法的指令自動執行，失效的移除並提示。卡牌指令記卡種不記位置。
- 戰局連續進行：AI 依設定步速出手、十分鐘前景計時、鏡頭與特效（炮擊拋物線、空投飛機、攻占波紋、斷補撤退煙霧、中立事件雷擊）即時播放。

## 操作

滑鼠左鍵拖曳平移、右鍵（或 Shift／Alt＋拖曳）旋轉俯仰、滾輪縮放；觸控單指平移、雙指縮放與旋轉；WASD／方向鍵平移、Q／E 旋轉、＋／－縮放、H 家園、F 前線、R 休整、空白鍵／P 暫停、Esc 取消。右上按鈕：家園、前線、全圖、旋轉 60°；右下小地圖點按跳轉。無 WebGL2 時顯示說明並連到平面版。
