# 三子循環棋立體版：獨立原型提案（尚未實作／未替換原遊戲）

## 先確認現有規則

`cyclic_tictactoe.html` 是 3×3 平面棋盤、8 條三連線。每人最多 3 顆，第四手起必須移動自己最早放下的棋（FIFO）。目的格必須在本手開始時就為空，不能把最早棋拿起再放回同一格。移除舊棋、放入新棋後才判勝。介面已標示接下來兩顆要移動的棋。AI 會找立即勝步，再看玩家回應；目前沒有三次重複局面或總步數和棋規則。

這次不修改此頁或規則。建議先另開「三子循環棋・三層試驗」原型，待討論後才決定是否進首頁。

## 可理解、可操作的最小方案

- 棋盤是三個 3×3 層，座標用「上／中／下層 + A–C 列 + 1–3 行」，共 27 格。
- 每人仍是 3 顆，保留 FIFO 與原本空格限制；不可吃子、不可原地續命。
- 同層橫／直／斜，以及跨三層的直線，都可以三連獲勝。程式用座標向量產生 49 條不重複直線：27 條軸線、18 條平面對角、4 條空間對角。
- 例：下 A1 → 中 B2 → 上 C3 是空間對角；下 B2 → 中 B2 → 上 B2 是垂直線；下 A1 → 中 A2 → 上 A3 是跨層斜線。彎線、折返、繞邊都不算。
- 手機把三個平面棋盤直向排列，每格至少 44px；桌機並排。點格前先預覽會移走的舊棋與新位置，再按「落子」確認。這避免 3D 透視遮住後排或手指選錯層。
- 同時顯示小型可旋轉立方體作輔助；它只負責看線，實際落子在平面層上。按住某一棋子可亮出其所有連線；勝線同時跨層連接並列出三個座標。
- 棋子標「1 下一顆、2、3 最新」，顏色加形狀雙重區分。預覽需先移除最早棋再顯示威脅，避免把即將消失的棋算進勝線。

## 勝負與循環

1. 正常完成一手後，若三顆在同一直線立即勝，優先於和棋條件。
2. 完整狀態三次出現則和棋。鍵必須包含雙方**有序佇列**、輪到誰、是否仍可交換選邊及控制方對應；只比較棋盤佔位會把不同未來走法誤判成同一局。
3. 另設 120 手上限（不是 120 組雙方回合），到限無人勝則和棋。介面顯示步數和已重複次數；AI 搜尋也必須使用同一和棋規則。
4. 保留先後手交換對局。單局採首手後交換選邊（pie rule）：第一方放 1 顆，第二方可接續或接管第一方顏色；交換只改控制方，棋與 FIFO 不重排，接著仍輪到另一顏色落子。此選擇需清楚解釋，不能偷偷改玩家顏色。

## 先手與趣味性：不能宣稱已平衡

中心格穿過 13 條線，明顯是開局熱點；直接讓固定玩家永遠先下中心，有偏差風險。交換選邊使開局方必須考慮對手接管強開局，能避免把「先搶中心」直接當成固定一方的特權。這是對開局誘因的處理，**不是 3D FIFO 遊戲已平衡或先手不可能必勝的證明**。

也有相反風險：27 格只有 6 顆，可能過度空曠。進入循環期，每方下一手保留的兩顆棋，至多決定一條三格直線與一個立即勝格；防守可能長期只需封那一格。但防守棋也會依 FIFO 被迫移走，所以必須把佇列順序納入分析。若實玩常形成重複封堵，應先重新討論規則，而不是偷偷增加棋子或給 AI 特權。

可討論的後續分支：每方改 4 顆、仍三連，增加同時威脅；或只開放兩個活動層。但這些會改變「三子」身分或增加規則負擔，不能與最小方案混在一起發布。第一輪建議先測忠於三子 FIFO 的版本。

## 小成本驗證計畫

- 規則單元測試：49 線唯一性、旋轉／鏡射對稱、跨層正反例、先移除再判勝、最早棋不能原地續命、非法點擊不改佇列。
- 和棋測試：相同佔位但不同佇列不算重複；真三次重複會和棋；120 手邊界及「同手勝利優先」；交換後顏色／AI／計時／歷史一致。
- 開局審核：對稱去重的首手種類，測交換／不交換；有限深度 alpha-beta 加節點預算，找可重現的短步強迫勝反例。未搜尋完的局面明列「未知」，不把搜尋不到勝法當成和棋證明。
- 趣味檢查：先做少量固定開局、交換先後手的 AI 對局與人類試玩，記錄重複和棋率、平均步數、跨層勝線比例、誤點次數。若需正式「無先手必勝」結論，另行批准完整可達狀態求解及可驗證證書；本批不做大型平衡模擬。
- UI 實測：桌機與手機直／橫向、三層定位、確認／取消落子、重開時取消舊 AI 計時器、勝線可讀性；實體 iPhone 尚需另測。
