# FuGames

FuLab 風格的靜態網頁遊戲集。遊戲與 AI 都在瀏覽器 JavaScript 內執行，不需要遊戲伺服器、帳號、外部資源或 npm 套件。各遊戲共用 `fulab-theme.css` 及本地 `icons.svg`。

## 本機預覽

在 repository 目錄執行：

```sh
python -m http.server 8000 --bind 0.0.0.0
```

開啟 `http://localhost:8000/`；圈地漫遊的網址是 `http://localhost:8000/territory_loop.html`。雲端環境可將 8000 port 轉送至本機預覽。此指令只提供本機靜態檔案，不會部署網站。

本次雲端 Chromium 的管理政策禁止 `file://`（`ERR_BLOCKED_BY_ADMINISTRATOR`），因此驗證與預覽使用本機 HTTP。遊戲不會向伺服器傳送遊戲狀態；頁面載入後已驗證可在離線模式繼續遊玩。

### 共用介面

首頁與所有遊戲都共用 `fulab-theme.css` 的配色、字體、導覽、標題、卡片、狀態列與按鈕。各頁只保留棋盤或遊戲畫面的專用樣式。玩法與設定預設收合；圈地漫遊以棋盤、領地比例、助手數量、遊玩時間和操作為主，不再同時展示側欄排行、進度卡與三步教學。

本地 SVG symbol 統一 48×48 viewBox、2px 描邊、圓角端點及安全留白；首頁圖示、頁面標題、操作與花色共用同一套幾何。棋子以 CSS／SVG、場內效果以 Canvas 幾何繪製。編號、形狀、虛線及雙框補充顏色，讓待移動棋子、合法牌、提示、勝利與危險狀態可分辨。

三款棋盤遊戲保留原有玩法；重複的新局／清空操作合併為「重新開始」。三子循環棋可用鍵盤啟動落子按鈕，結束後變更提示設定不會重新開放落子。軌道棋保留悔棋、提示與 AI 設定，重開時會作廢舊局尚未完成的動畫／AI 回呼。

### 星點吞噬

青綠色玩家與四位 AI 競逐光點。小光點增加 2 質量，大光點增加 5，並逐漸補充。比對手重至少 20% 且包住其中心時可吞噬，取得對手 80% 質量；大小相近者可穿過彼此。撞牆會停住，不會出局。

先達 160 質量或成為唯一存活者即勝。90 秒結束時，存活者質量最大者勝，並列最高為平手；被吞噬則失敗。

- 桌機：按住方向鍵／WASD 移動，或用滑鼠指向棋盤內的目的地。
- 手機：在棋盤任一處按住拖曳，以相對偏移控制移動，放開停止。
- 空白鍵／衝刺鈕加速 0.6 秒，冷卻 4 秒，不扣質量。
- P／Esc 暫停或繼續；切換視窗自動暫停。重開有確認與取消。

`star_feast.html` 內的 `growth-engine` 是固定 20ms 步長的純 JavaScript 模擬，包含移動、圓形碰撞、成長、吞噬及勝負。AI 會優先躲避附近威脅，其次追逐較小對手或找光點；靠牆時調整逃跑方向。`growth-ui` 負責 Canvas 與鍵盤／滑鼠／觸控輸入。無遊戲伺服器或新執行依賴。

### 圈地漫遊

玩家是青綠圓形首領，另有珊瑚、紫藤、琥珀三個 AI 陣營。離開己方領地留下虛線，回到己方色塊取得路徑及完全封閉的區域；四邊 flood fill 判定圈地，地圖邊界本身不充當封閉線。整局持續進行，沒有領地百分比目標、倒數、最後存活者或勝負終止；畫面顯示已玩時間，可隨時暫停或重開。

- **基地與斷連**：每陣營的房子圖示是固定基地。領地只保留與基地上下左右連通的部分，切斷狹窄補給線可讓外圍土地變回空白；搶下基地則擊退整個陣營。
- **首領與重生**：首領自己撞線、被切線或基地失守時，同陣營的土地、路徑和助手撤退。約 3.6–4.2 秒後在安全位置重生；找不到安全位置會每 1.2 秒重試。玩家同樣會重生，其他陣營在等待期間繼續運作。敵方以相同色彩、增加代數的新首領補入。
- **安全補入**：候選 5×5 基地避開角色（中心與角色的 Chebyshev 距離至少 5）、所有路徑、其他基地及出生保護土地，優先空白與遠離角色處。滿圖時可以收回安全邊緣土地，讓新陣營仍有入場機會；這也會重新計算土地連通。新基地有 2.4 秒保護，首領一離開己方土地就解除。
- **助手成長**：60／120／200 格土地分別解鎖自然補充 1／2／3 名助手，每次補充間隔至少 5.4 秒。助手共享陣營土地，各自規劃圈地和攻擊；被切線只損失助手本身。土地縮小不直接刪除現有助手，但缺額依目前土地量補充。
- **接觸倒戈**：首領或助手碰到敵方助手，會將被碰到的助手招降；助手碰到敵方首領，則加入該首領。助手互撞時由本步移動方招降接觸方。每步輪換全部角色的行動順序，避免固定陣營總是先手。倒戈清除助手舊路徑和計畫；白色光環期間（1.8 秒）不能招降或被招降，阻止原地連鎖翻轉。首領不會倒戈，身體相撞本身不淘汰首領。
- **數量上限**：固定 4 個首領、12 個共用助手槽，合計最多 16 個角色。招降只轉移現有角色，可以超過單陣營自然解鎖數。沒有隨時間累積的角色或事件陣列。
- **操作**：方向鍵／WASD、棋盤滑動或觸控方向鈕轉向，不能直接反向。撞地圖邊界或友方虛線會停住，轉向可繼續；友方虛線不會互相覆寫。空白鍵／P 暫停或繼續，Esc 暫停；切換視窗自動暫停。「重新開始」先確認，也能保留本局。

AI 會在可達的領地邊緣選擇圈地路線，評估面積、接近前線的移動成本、敵方土地、基地和狹窄補給連接，並考慮敵人對路徑的威脅。每數步重新觀察可追切的敵方虛線（家中最多 8 格、外出最多 3 格）、附近可招降助手；遇到暴露路徑被逼近或畫線太長時尋路回家。退路完全被封且連續 8 次無路可走的 AI 會撤退，防止永遠卡住。首領上方顯示「擴張／侵入／截地／斷線／招降／回防」，狀態列優先呈現玩家相關事件。

同一個 HTML 內的 `game-engine` 是固定 150ms 步長的純 JavaScript 模擬，棋盤存陣營 ID、路徑存角色 ID；`game-ui` 處理 Canvas 與輸入。AI 每四步移動三步，玩家每步移動。遊戲與所有 AI 都在本機運算，不做真實多人連線。

### 四人拉密

整合使用者提供的 `FuLab-Rummikub.html`，保留四人規則、搜尋型 AI、拖放、提示、撤回與瀏覽器存檔；首頁與遊戲頁使用 FuGames 導覽、圖示及共用樣式。高手／大師／極限搜尋預算為 0.7／2.5／8 秒；Worker 無法使用時自動改為最多 2.5 秒的頁面內搜尋。起手需要至少 30 點，之後可合法重排公共牌桌；四人在空牌池連續跳過後結算。非官方個人遊戲。

## 驗證

Repository 不需要建置指令或 package manifest。`Game rules` GitHub Actions workflow 在 push／pull request 執行全部 Node 規則與固定種子模擬；既有 GitHub Pages 部署仍由儲存庫設定管理，沒有新增部署服務。瀏覽器驗證在本機 Chromium 執行；測試工具不是遊戲執行依賴。

### 規則測試（Node.js 18 以上）

```sh
node --test tests/*.test.cjs
git diff --check
```

直接擷取 HTML 內實際使用的引擎執行，涵蓋圈地／搶地、四邊開放判定、補給斷連、基地失守、自撞／切線、助手解鎖與雙向倒戈、倒戈保護、友方路徑、重生／安全補入、快速輸入、暫停／重開、AI 跨格追擊／前線侵入／返家、全滿員上限及遊戲清單。六個固定種子各模擬 8,000 步（20 分鐘），共 120 分鐘，逐段檢查持續圈地並驗證有界角色、路徑一致、攻擊、倒戈與反覆重生。輸出總事件量與執行時間；它是邏輯模擬成本，並非實體手機 FPS。

星點吞噬另覆蓋光點成長、吞噬門檻、碰撞、衝刺冷卻、四面牆、輸入向量、暫停／重開、勝負、AI 覓食／追逐／逃跑及 30 場固定種子完整比賽。
